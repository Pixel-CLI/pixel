## Common Comparative Protocol

Each track is evaluated against the same criteria:

- **Reproductibilité**: Can the result be reproduced from the documented steps?
- **Vérifiabilité**: Is there a deterministic check that confirms the claim?
- **Couverture**: Does the track cover the full scope of the comparison?
- **Limites**: Are the boundaries of the comparison explicitly stated?
