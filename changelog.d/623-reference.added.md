**reference:** `pixel reference add/list/setup/query/remove` manages version-pinned external corpora under `.pixel/references/`, recorded in `.pixel/reference.json` with role, licence and provenance. `setup` clones or fetches each entry to its exact revision — a fetched branch pin is checked out detached at the commit the fetch wrote, and an annotated tag is peeled to its commit — and validates every revision with `pixel_git::validate_ref` before it reaches git, so a hand-edited manifest cannot inject a git flag. `query` reports each pinned corpus's status cold, without fetching or modifying source.
