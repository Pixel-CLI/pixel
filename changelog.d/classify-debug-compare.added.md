**classify:** `pixel classify --debug` asks every configured engine — the local Ollaya daemon, the stored remote chat preset, and Jev — the same labeled question in parallel and prints each one's probabilities or its per-engine error row (`--json` for scripting) — `--remote-model` and `PIXEL_REMOTE_*` reach only the selected preset's lane, so a Jev lane beside another preset never sends its key to that preset's proxy; `pixel config remote-preset <preset> [--model --base]` selects the remote provider, model and endpoint without editing the YAML, and `pixel config classify-engine` now accepts `jev` as a first-class choice.
