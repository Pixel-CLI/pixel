**daemon, proto:** the `targets_facts` packet (`pixel scope-task --read-only`) carries `facts.relevance`, algorithm version 2: per task keyword, how many files contain it, define a symbol named with it or carry it in a path (a French keyword borrows its first matching synonym), and the co-files they meet in, weighted by how rare each word is. `pixel_daemon::relevance::relevance_on` computes it without a daemon. The packet's caps now reach the response's `epistemics` and `warnings`. A request with `relevance_only: true` returns the same block without ranking targets (`facts` is `{envelope, relevance}`), for a reader that only gates on relevance.
