**setup:** at a terminal `pixel setup` asks which agents to write for and which features to switch on, lists every instruction file, hook step and setting with the exact managed block, and writes nothing until you confirm; it registers the hooks of the agents and features picked. `--print` renders the default block; without a terminal, in CI or with `--yes`/`--json` it is the unattended installer, unchanged; `--remove` also strips the block.
