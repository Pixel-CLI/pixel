**mutants:** the pre-push mutation gate no longer ships the diff over ssh to the `a2` gate host, which is retired with `scripts/mutants-gate-host.sh`. The gate (`scripts/mutants-push-gate.sh`, formerly `mutants-remote-gate.sh`) is now opt-in: `PIXEL_MUTANTS_GATE=local` runs the CI-equivalent campaign (`mutants-preflight.sh --run`, pinned nightly and cargo-mutants) on the pushing machine — meant for cloud agent sessions — and blocks on its verdict; unset or `off` leaves the verdict to `Mutants in diff`, and any other value refuses the push. `PIXEL_MUTANTS_GATE_HOST`, `PIXEL_MUTANTS_GATE_SCRIPT` and `PIXEL_MUTANTS_GATE_OUT` are gone.
