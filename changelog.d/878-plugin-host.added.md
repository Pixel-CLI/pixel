**plugin:** `pixel plugin list|add|remove|enable|trust` and a plugin host (API 1, `command` capability): `pixel <name> [args]` runs a trusted repo plugin, a `~/.pixel/plugins/<name>/` plugin or `pixel-<name>` on PATH with `PIXEL_API`, `PIXEL_REPO_ROOT`, `PIXEL_GRAPH_DB` and `PIXEL_BIN` set. Repo plugins need `pixel plugin trust` (any file change revokes it); `network = true` plugins need `pixel plugin enable`.
