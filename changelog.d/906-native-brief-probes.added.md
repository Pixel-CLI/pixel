**brief:** the prompt-submit brief runs probes itself. A probe is a plugin with the new `brief-probe` capability (a `[brief-probe]` table: when it runs, `budget_ms`, lead or append); `pixel setup` installs seven first-party ones into `~/.pixel/plugins`, `pixel plugin disable <name>` / `enable` switch one, `PIXEL_BRIEF_PROBES=0` all. They run in parallel inside the window, a failing one is skipped, each run is logged in `brief-decisions.jsonl`.
