**plugin:** `pixel install <source>` installs a plugin from `github:<owner>/<repo>[@<ref>]`, a git URL or a local directory (`--name` picks one plugin out of a repository). A `github:` plugin whose program is not committed gets the release asset `pixel-<name>-<target-triple>` (checked against `<asset>.sha256` when one is published); without an asset the `cargo install --git` command is printed and `pixel plugin list` marks the plugin not runnable. `npm:<package>` exits 2 with a not-yet reason. A manifest may list `commands = [...]`: `pixel <command>` then runs that plugin as `<run> <command> <args…>` (one binary, many commands, as `pixel-git` does); `pixel plugin list` shows them and flags a command two plugins share. `pixel uninstall <name>` replaces `pixel plugin remove`, and `pixel plugin add` is gone. The hint for a moved command now reads `pixel install github:Pixel-CLI/<repo>`; `PIXEL_GITHUB_BASE_URL` redirects `github:` sources to a mirror.
