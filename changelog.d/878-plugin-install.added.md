**plugin:** `pixel install <source>` installs a plugin from `github:<owner>/<repo>[@<ref>]`, a git URL or a local directory (`--name` picks one out of several). A `github:` plugin whose program is not committed gets the release asset `pixel-<name>-<target-triple>` (checked against its `.sha256` when published); otherwise the `cargo install --git` command is printed and `pixel plugin list` marks it not runnable. `npm:` exits 2 (not supported yet). A manifest may list `commands = [...]` so one binary serves several commands; a command two plugins share is an error. `pixel uninstall <name>` replaces `pixel plugin remove`; `pixel plugin add` is gone. `PIXEL_GITHUB_BASE_URL` redirects `github:` sources.
