**install:** a project Codex install written by a side build (`pixel-dev install --repo .`) can be handed back to the managed `pixel install --repo .`: pixel's own PreToolUse group is recognised at any Pixel executable path, and config and backup move to the managed spelling in one pass, even after an install interrupted between the two. A user edit to that group (a hook, matcher or timeout), a foreign command, or another backup is still refused.
