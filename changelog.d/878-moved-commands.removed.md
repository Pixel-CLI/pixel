**cli:** `workspace`, `flow`, `plan-rollback`, `coverage`, `token-savings`, `index-stats`, `squash-branch` and `fast-forward` left the binary and ship as plugins of `Pixel-CLI/pixel-plugins` (`pixel plugin add https://github.com/Pixel-CLI/pixel-plugins --name <name>`). Without the plugin each prints that command and exits 2; `rescue`, `stats`, `update`, `savings`, `rewrite` and `replay-flow` resolve to the plugin of the current name. `--workspace` on `impact` and `who-calls` stays in the core.
