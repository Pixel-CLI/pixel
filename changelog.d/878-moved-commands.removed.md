**cli:** `flow`, `plan-rollback`, `token-savings`, `squash-branch` and `fast-forward` left the binary and ship as plugins of `Pixel-CLI/pixel-plugins` (`pixel plugin add https://github.com/Pixel-CLI/pixel-plugins --name <name>`). Without the plugin each prints that command and exits 2; `rescue`, `update`, `savings`, `rewrite` and `replay-flow` resolve to the plugin of the current name.
