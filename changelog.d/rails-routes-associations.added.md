**graph:** Rails routes are indexed: `pixel find-code "POST /admin/orders"` returns the declaring line in `config/routes.rb` with its handler (`admin/orders#create (Admin::OrdersController#create)`), and `impact` on a controller action lists the route that dispatches to it. Active Record associations reference the model class Rails would load (`class_name:` and namespaces honoured); polymorphic ones, `through:` ones without `class_name:` and computed names reference nothing.
