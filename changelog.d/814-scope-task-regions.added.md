**scope:** `scope-task --regions` writes `.pixel/regions.json` beside `targets.json`: symbol line ranges + context reference, conservative conflict pairs with reasons (same file / call edge / import adjacency / same name / graph unavailable), merge-order layers from the condensed call graph (callees before callers), and declared shared files (imported by ≥2 region files, with importers as witness). Conflict detection over-approximates — when in doubt, two regions conflict; a false conflict only costs serialization, a false "disjoint" costs a broken merge. Every claim carries a witness; caps ride the epistemics envelope; the manifest is evidence, never an action recommendation. Pixel emits the manifest only — orchestration (agent count, scheduling, merging) stays with the harness. `--no-manifest` and `--read-only` suppress it.
