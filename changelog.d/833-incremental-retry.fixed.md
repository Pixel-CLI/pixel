**graph:** an incremental update re-decides only the unresolved calls and Ruby receiver edges its batch can change — calls to a definition the batch added, removed or changed, calls from a file importing a changed one, Ruby receivers naming a changed class, module or method owner — instead of rereading every unresolved row and replaying every Ruby receiver edge. A file rewritten with the same definitions re-decides nothing outside itself, so a one-file edit on a large Ruby repository no longer pays a cost proportional to the whole graph.
