The three rates are the saving on each kept file of the well-known files table: the whole file against pixel list-signatures on it, UTF-8 bytes divided by four on both sides, Pixel's answer already subtracted. The median of an even count is the mean of the two middle files.

What it leaves out: a file read stays in the context and is sent again on every later turn (usually from the cache, billed lower), so a real session pays for it more than once; output tokens do not change; and the files measured run {{ $fmtFull.fullMin }} to {{ $fmtFull.fullMax }} tokens, so much smaller files may save less.
